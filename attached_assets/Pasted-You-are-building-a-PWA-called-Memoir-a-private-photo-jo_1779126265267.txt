You are building a PWA called Memoir — a private photo journal app. The entire app is a single index.html file. No frameworks, no build steps, no backend, no database. Everything is vanilla HTML, CSS, and JavaScript. Data lives in GitHub repositories via the GitHub API.

Core concept
Each user has a private GitHub repo (memoir-data) that stores their posts, friends list, and config. A shared private repo (memoir-shared) owned by the network host stores the music library, friend inbox, and email alerts. The app is hosted on GitHub Pages at a public URL but contains no tokens — tokens are entered by users during setup and stored encrypted in localStorage.

Data layer — DataSource
Every GitHub API call goes through a single DataSource object. Nothing calls GitHub directly. This is the most important architectural piece.
javascriptconst DataSource = {
  sources: {
    personal: { owner: null, repo: null, token: null },
    network:  { owner: null, repo: null, token: null },
    friends:  {}
    // friends structure:
    // { alice: { owner: 'alice-gh', repo: 'memoir-data', token: 'ghp_ALICE_READONLY' } }
  },

  resolve(source) {
    if (source === 'personal') return this.sources.personal
    if (source === 'network')  return this.sources.network
    if (source.startsWith('friend:')) {
      const name = source.split(':')[1]
      return this.sources.friends[name]
    }
    throw new Error(`Unknown source: ${source}`)
  },

  async get(source, path) {
    // Fetches a file from GitHub, decodes base64, parses JSON
    // Returns null on 404
    // Throws with .status on other errors
  },

  async getRaw(source, path) {
    // Returns the raw GitHub API response object (for sha, download_url etc)
  },

  async getFreshUrl(source, path) {
    // Always re-fetches download_url from GitHub API
    // Never caches — private repo URLs expire
    const info = await this.getRaw(source, path)
    return info?.download_url || null
  },

  async getFolderUrls(source, folderPath) {
    // Lists a folder, returns { filename: download_url } map
    const items = await this.ghGet(source, folderPath)
    const map = {}
    if (Array.isArray(items)) {
      items.forEach(f => { if (f.download_url) map[f.name] = f.download_url })
    }
    return map
  },

  async put(source, path, content, message) {
    // Writes a file to GitHub (creates or updates)
    // Handles getting existing sha automatically
    // content can be object (gets JSON stringified) or ArrayBuffer (binary)
  },

  async putBinary(source, path, arrayBuffer, message) {
    // Uploads binary data (images, audio) to GitHub
  },

  async delete(source, path, message) {
    // Deletes a file (fetches sha automatically)
  },

  async listFolder(source, folderPath) {
    // Returns array of { name, sha, download_url, size } for a folder
    // Returns [] if folder doesn't exist
  },

  // Internal GitHub fetch — handles auth headers, error detection
  async ghFetch(source, path, options = {}) {
    const { owner, repo, token } = this.resolve(source)
    const url = path.startsWith('http')
      ? path
      : `https://api.github.com/repos/${owner}/${repo}/contents/${path}`
    const res = await fetch(url, {
      ...options,
      headers: {
        'Authorization': `Bearer ${token}`,
        'Accept': 'application/vnd.github.v3+json',
        'Content-Type': 'application/json',
        ...(options.headers || {})
      }
    })
    if (res.status === 401) { handleTokenFailure(source); throw Object.assign(new Error('Unauthorized'), { status: 401 }) }
    if (res.status === 403) { handleTokenScope(source); throw Object.assign(new Error('Forbidden'), { status: 403 }) }
    if (res.status === 429) { handleRateLimit(res); throw Object.assign(new Error('Rate limited'), { status: 429 }) }
    if (!res.ok && res.status !== 404) throw Object.assign(new Error(`GitHub ${res.status}`), { status: res.status })
    return res
  }
}

Boot sequence
javascriptasync function boot() {
  // 1. Register service worker
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('./sw.js').catch(() => {})
  }

  // 2. Detect URL hash for special modes
  const hash = window.location.hash.slice(1)
  if (hash.startsWith('owner')) {
    // Show owner setup mode
    showOwnerSetup()
    return
  }
  if (hash.startsWith('invite=')) {
    const code = decodeInviteCode(hash.slice(7))
    state.pendingInvite = code
    // Will be used during setup
  }
  if (hash.startsWith('connect=')) {
    const code = decodeConnectCode(hash.slice(8))
    state.pendingConnect = code
  }

  // 3. Try loading saved auth
  const auth = await loadAuth()
  if (!auth) {
    navigateTo('screen-setup')
    return
  }

  // 4. Initialize DataSource
  state.auth = auth
  DataSource.sources.personal = {
    owner: auth.username,
    repo: 'memoir-data',
    token: auth.token1
  }
  DataSource.sources.network = {
    owner: auth.networkOwner,
    repo: auth.networkRepo,
    token: auth.token3
  }

  // Load friends into DataSource
  await loadFriends()

  // 5. Navigate to feed
  navigateTo('screen-feed', false)
  state.navHistory = ['screen-feed']
  setActiveTab('feed')

  // 6. Run boot checks in parallel
  await Promise.allSettled([
    loadFeed(),
    checkInbox(),
    checkFriendOutboxes(),
    loadMusicIndex(),
    checkTokenHealth()   // only if last check > 6 hours ago
  ])

  // 7. Handle pending connect (existing user adding friend)
  if (state.pendingConnect) {
    handlePendingConnect(state.pendingConnect)
  }
}

javascript// Called after friend setup completes, or when existing user pastes connect code
async function completePairing(friendData) {
  // friendData = { username, repoOwner, repo, readToken, email? }

  // 1. Add to DataSource
  DataSource.sources.friends[friendData.username] = {
    owner: friendData.repoOwner,
    repo: friendData.repo,
    token: friendData.readToken
  }

  // 2. Save to personal repo
  await DataSource.put('personal', `friends/${friendData.username}.json`, friendData)

  // 3. Drop note in their inbox via network repo
  await DataSource.put('network',
    `inbox/${friendData.username}/from-${state.auth.username}.json`, {
      username: state.auth.username,
      repoOwner: state.auth.username,
      repo: 'memoir-data',
      readToken: state.auth.token2,
      email: state.auth.email || '',
      connectedAt: new Date().toISOString()
    }
  )

  // 4. Update local state
  state.friends[friendData.username] = friendData
}

// Called on every boot
async function checkInbox() {
  try {
    const files = await DataSource.listFolder('network', `inbox/${state.auth.username}`)
    for (const file of files) {
      if (file.name === '.gitkeep') continue
      const data = await DataSource.get('network', `inbox/${state.auth.username}/${file.name}`)
      if (!data) continue

      if (data.type === 'token2_update') {
        // A friend rotated their read token — update silently
        if (state.friends[data.fromUsername]) {
          state.friends[data.fromUsername].readToken = data.newReadToken
          DataSource.sources.friends[data.fromUsername].token = data.newReadToken
          await DataSource.put('personal', `friends/${data.fromUsername}.json`,
            state.friends[data.fromUsername])
        }
      } else {
        // New friend connection request
        await completePairingFromInbox(data)
        showToast(`${data.username} connected with you`, '', 'success')
      }

      // Delete processed file
      await DataSource.delete('network', `inbox/${state.auth.username}/${file.name}`)
    }
  } catch {}
}

Token health check
javascriptasync function checkTokenHealth() {
  const lastCheck = localStorage.getItem('memoir_health_check')
  if (lastCheck) {
    const hoursSince = (Date.now() - parseInt(lastCheck)) / 3600000
    if (hoursSince < 6) return
  }
  localStorage.setItem('memoir_health_check', Date.now().toString())

  const results = {}

  // Test Token 1 — call /user
  try {
    await fetch('https://api.github.com/user', {
      headers: { 'Authorization': `Bearer ${state.auth.token1}` }
    }).then(r => { results.token1 = r.ok ? 'healthy' : (r.status === 401 ? 'expired' : 'error') })
  } catch { results.token1 = 'error' }

  // Test Token 2 — read public-card.json using token2 specifically
  try {
    const r = await fetch(
      `https://api.github.com/repos/${state.auth.username}/memoir-data/contents/.memoir/public-card.json`,
      { headers: { 'Authorization': `Bearer ${state.auth.token2}` } }
    )
    results.token2 = r.ok ? 'healthy' : (r.status === 401 ? 'expired' : 'error')
  } catch { results.token2 = 'error' }

  // Test Token 3 — read music-index using token3
  try {
    const r = await fetch(
      `https://api.github.com/repos/${state.auth.networkOwner}/${state.auth.networkRepo}/contents/music/music-index.json`,
      { headers: { 'Authorization': `Bearer ${state.auth.token3}` } }
    )
    results.token3 = r.ok ? 'healthy' : (r.status === 401 ? 'expired' : 'error')
  } catch { results.token3 = 'error' }

  state.tokenHealth = results
  renderTokenHealthBanners(results)

  // Trigger email alerts for failures
  for (const [key, status] of Object.entries(results)) {
    if (status === 'expired' || status === 'error') {
      await triggerEmailAlert(key, status)
    }
  }
}

async function triggerEmailAlert(tokenKey, status) {
  if (!state.auth.email) return
  const today = new Date().toISOString().split('T')[0]
  const alertPath = `alerts/${state.auth.username}/alert-${tokenKey}-${today}.json`
  
  // Check if already sent today
  try {
    const existing = await DataSource.get('network', alertPath)
    if (existing) return
  } catch {}

  await DataSource.put('network', alertPath, {
    type: `${tokenKey}_${status}`,
    recipientEmail: state.auth.email,
    username: state.auth.username,
    triggeredAt: new Date().toISOString()
  })
}

function renderTokenHealthBanners(results) {
  const messages = {
    token1: { label: 'personal token', impact: 'Posts won\'t save until fixed.' },
    token2: { label: 'read token',     impact: 'Friends can\'t see your posts.' },
    token3: { label: 'network token',  impact: 'Music and sharing unavailable.' }
  }
  for (const [key, status] of Object.entries(results)) {
    if (status !== 'healthy') {
      const { label, impact } = messages[key]
      showBanner(`⚠ Your ${label} needs attention. ${impact}`, key)
    }
  }
}

Post creation
javascriptasync function submitPost() {
  const postId = generatePostId()
  const caption = document.getElementById('caption-input').value.trim()
  const location = document.getElementById('location-input').value.trim()
  const selectedSong = state.selectedSongId
    ? state.musicIndex.find(s => s.id === state.selectedSongId)
    : null

  const mediaEntries = []
  let thumbnailPath = null

  // Upload each media file
  for (let i = 0; i < state.pendingMedia.length; i++) {
    const file = state.pendingMedia[i]
    const isVideo = file.type.startsWith('video/')
    const ext = file.name.split('.').pop().toLowerCase()
    const filename = `media_${i + 1}.${ext}`

    await DataSource.putBinary('personal', `posts/${postId}/${filename}`,
      await file.arrayBuffer())
    mediaEntries.push({ filename, type: isVideo ? 'video' : 'image', order: i + 1 })

    // Generate and upload low-res thumbnail for first image
    if (i === 0 && !isVideo) {
      const thumbBlob = await generateThumbnail(file, 180, 135, 0.65)
      if (thumbBlob) {
        await DataSource.putBinary('personal', `posts/${postId}/thumb.jpg`,
          await thumbBlob.arrayBuffer())
        thumbnailPath = `posts/${postId}/thumb.jpg`
      } else {
        thumbnailPath = `posts/${postId}/${filename}`
      }
    }
  }

  // Copy song from shared music repo to post folder
  let songMeta = null
  if (selectedSong) {
    const songUrl = await DataSource.getFreshUrl('network', `music/${selectedSong.filename}`)
    const songResp = await fetch(songUrl, {
      headers: { 'Authorization': `Bearer ${state.auth.token3}` }
    })
    const songBuffer = await songResp.arrayBuffer()
    await DataSource.putBinary('personal', `posts/${postId}/song.mp3`, songBuffer)
    songMeta = {
      title: selectedSong.title,
      artist: selectedSong.artist,
      filename: 'song.mp3',
      trimStart: state.createTrimStart || 0,
      trimEnd: state.createTrimEnd || null
    }
  }

  // Write meta.json
  await DataSource.put('personal', `posts/${postId}/meta.json`, {
    id: postId,
    createdAt: new Date().toISOString(),
    updatedAt: new Date().toISOString(),
    caption,
    location,
    media: mediaEntries,
    song: songMeta
  })

  // Update posts-index.json
  const indexFile = await DataSource.getRaw('personal', 'posts-index.json')
  const currentIndex = indexFile
    ? JSON.parse(atob(indexFile.content.replace(/\n/g, '')))
    : []
  const newEntry = {
    id: postId,
    date: postId.split('-').slice(0, 3).join('-'),
    captionPreview: caption.slice(0, 120),
    location,
    thumbnail: thumbnailPath,
    songTitle: songMeta?.title || null,
    songArtist: songMeta?.artist || null,
    mediaCount: mediaEntries.length,
    hasVideo: mediaEntries.some(m => m.type === 'video')
  }
  await DataSource.put('personal', 'posts-index.json',
    [newEntry, ...currentIndex], `memoir: create post ${postId}`)
}

javascript// Runs on every boot
async function checkFriendOutboxes() {
  for (const [username, friendData] of Object.entries(state.friends)) {
    try {
      const files = await DataSource.listFolder(`friend:${username}`, `outbox/to-${state.auth.username}`)
      const shareFiles = files.filter(f => f.name.endsWith('.json') && f.name !== '.gitkeep')

      const lastSeen = state.lastSeen[username]
        ? new Date(state.lastSeen[username])
        : new Date(0)

      let latestTimestamp = lastSeen

      for (const file of shareFiles) {
        const share = await DataSource.get(`friend:${username}`,
          `outbox/to-${state.auth.username}/${file.name}`)
        if (!share) continue

        const shareTime = new Date(share.timestamp)
        if (shareTime <= lastSeen) continue

        // New share
        if (!state.chats[username]) state.chats[username] = []
        state.chats[username].unshift({ ...share, fromMe: false })

        if (shareTime > latestTimestamp) latestTimestamp = shareTime
      }

      if (latestTimestamp > lastSeen) {
        state.lastSeen[username] = latestTimestamp.toISOString()
        localStorage.setItem('memoir_last_seen', JSON.stringify(state.lastSeen))
        updateChatBadge(username)
      }
    } catch {}
  }
}

Thumbnail generation
javascriptfunction generateThumbnail(file, maxW = 180, maxH = 135, quality = 0.65) {
  return new Promise((resolve) => {
    if (!file.type.startsWith('image/')) { resolve(null); return }
    const img = new Image()
    const url = URL.createObjectURL(file)
    img.onload = () => {
      URL.revokeObjectURL(url)
      const scale = Math.min(maxW / img.width, maxH / img.height, 1)
      const w = Math.round(img.width * scale)
      const h = Math.round(img.height * scale)
      const canvas = document.createElement('canvas')
      canvas.width = w
      canvas.height = h
      canvas.getContext('2d').drawImage(img, 0, 0, w, h)
      canvas.toBlob(blob => resolve(blob), 'image/jpeg', quality)
    }
    img.onerror = () => { URL.revokeObjectURL(url); resolve(null) }
    img.src = url
  })
}

async function uploadSong(file, title, artist) {
  const ext = file.name.split('.').pop().toLowerCase()
  const id = slugify(`${title}-${artist}`)
  const filename = `${id}.${ext}`

  await DataSource.putBinary('network', `music/${filename}`, await file.arrayBuffer())

  const current = await DataSource.get('network', 'music/music-index.json') || []
  await DataSource.put('network', 'music/music-index.json', [
    ...current,
    { id, title, artist, filename, sizeBytes: file.size, addedOn: new Date().toISOString().split('T')[0] }
  ])

  state.musicIndex = [...current]
}

async function previewSong(song) {
  // Get fresh URL — private repo URLs expire
  const url = await DataSource.getFreshUrl('network', `music/${song.filename}`)
  const audio = new Audio(url)
  // Handle error → re-fetch URL
  audio.onerror = async () => {
    const freshUrl = await DataSource.getFreshUrl('network', `music/${song.filename}`)
    audio.src = freshUrl
    audio.play().catch(() => {})
  }
  audio.play().catch(() => {})
  return audio
}

Audio player (post view)
javascriptasync function loadAndPlaySong(postId, songMeta) {
  const audio = document.getElementById('audio-player')

  // Always fetch fresh blob — private repo URLs expire
  const freshUrl = await DataSource.getFreshUrl('personal', `posts/${postId}/song.mp3`)
  const resp = await fetch(freshUrl, {
    headers: { 'Authorization': `Bearer ${state.auth.token1}` }
  })
  const blob = await resp.blob()

  if (audio._blobUrl) URL.revokeObjectURL(audio._blobUrl)
  audio._blobUrl = URL.createObjectURL(blob)
  audio.src = audio._blobUrl

  const trimStart = songMeta.trimStart || 0
  const trimEnd = songMeta.trimEnd || null

  audio.addEventListener('loadedmetadata', () => {
    if (trimStart > 0) audio.currentTime = trimStart
  }, { once: true })

  audio.ontimeupdate = () => {
    const end = trimEnd || audio.duration
    if (audio.currentTime >= end) audio.currentTime = trimStart
    const elapsed = audio.currentTime - trimStart
    const total = end - trimStart
    updateProgressBar(elapsed / total)
    updateTimeDisplay(elapsed, total)
  }

  await audio.play()
}

Key implementation rules
Private repo URLs expire — never cache download_url values. Always call DataSource.getFreshUrl() to get a current URL before loading any image, video, or audio. On img.onerror, re-fetch a fresh URL and retry.
Audio — always fetch as a blob via authenticated request, create a blob URL, set as audio.src. Never set a GitHub download_url directly as audio src — it will fail on private repos due to CORS.
Images in feed — use low-res thumb.jpg (generated client-side at 180×135px). Use IntersectionObserver to lazy-load. Always re-fetch the download_url from the API — never store it in posts-index.json.
All GitHub writes — must fetch current file sha before updating. Use DataSource.put() which handles this automatically.
Token failures — every DataSource call catches 401/403. On 401: show specific banner for that token, keep rest of app working. Never crash the whole app because one token fails.
Song in post — always copy the song file from memoir-shared/music/ into posts/postId/song.mp3 during post creation. Posts must be self-contained. Do not reference the shared music repo from a post.
Object-fit for images — use object-fit: contain with a blurred background behind it. Never use object-fit: cover which crops the image. The blurred background is generated from the same image URL.
Reorder — use pointer events on drag handles, not HTML5 drag API. HTML5 drag is unreliable on mobile.
Song trim — store trimStart and trimEnd as seconds in meta.json under the song object. Audio player seeks to trimStart on load and loops back to trimStart when currentTime reaches trimEnd.
